# Cybersecurity_Lab_Build_Report
Cybersecurity Lab Build and Web Application Security Testing

Internship Practical Project
This project demonstrates the setup and implementation of a cybersecurity testing lab using Kali Linux and VirtualBox.

Tools Used
- Kali Linux
- VirtualBox
- Docker
- OWASP Juice Shop
- Burp Suite
- Wireshark
- Nmap

Project Activities
- Virtual lab configuration
- Docker installation and verification
- OWASP Juice Shop deployment
- HTTP traffic interception using Burp Suite
- Packet capture using Wireshark
- Network validation using Ping and Nmap
- Authentication and web application testing

Deliverables
- Full PDF report
